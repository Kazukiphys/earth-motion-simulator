季節をつくるもの

KEY NOTES
  1. 01地球の地軸は，公転中もほぼ同じ方向を向き続けます。
  2. 02傾いた半球ほど日差しが強く，昼も長くなります。
  3. 03北半球が夏のとき，南半球では冬。距離が主な原因ではありません。

食が起きる条件

KEY NOTES
  1. 01日食は新月，月食は満月のときに起こりえます。
  2. 02さらに月が，月軌道と黄道面の交点近くにいる必要があります。
  3. 03軌道が5.1°傾いているため，多くの新月・満月では影が外れます。
  4. 04交点の向きは約18.6年で一周し，食が起きやすい時期も巡ります。

同じ時刻を二つの視点で

SAME DATE
  1. 01左は太陽中心の軌道，右は地球から見た背景恒星上の位置です。
  2. 02地球が外側の惑星を追い越す間，空では惑星が逆向きに動いて見えます。
  3. 03惑星の公転方向は変わらず，逆行は地球から見た見かけの動きです。
  4. 04右は東京付近から見た年間星図です。星空の背景を固定し，惑星がその上をどう移動するかを示します。
  5. 05色付き破線は東京から見た軌跡，金色の黄道線は太陽の通り道です。火星の実際の公転軌道とは別の線です。
  6. 06視線は東京の地表位置（北緯35.6762°，東経139.6503°）から計算し，地球中心からの視差も含めています。
  7. 07右側は夜空だけを表示し，太陽は描きません。左の太陽は太陽系図の軌道中心です。
※ 太陽の南中高度・日照時間は北緯 35°での概算です。軌道の形・天体の大きさは模式図です。月の距離は表示のため縮めています。
